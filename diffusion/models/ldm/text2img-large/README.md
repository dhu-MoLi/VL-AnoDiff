# Pre-trained Diffusion Model

Download the Latent Diffusion text2img model checkpoint and place it here:

```bash
mkdir -p models/ldm/text2img-large/
wget -O models/ldm/text2img-large/model.ckpt \
  https://ommer-lab.com/files/latent-diffusion/nitro/txt2img-f8-large/model.ckpt
```

This file is ~5.8 GB and is **not** included in the repository.
